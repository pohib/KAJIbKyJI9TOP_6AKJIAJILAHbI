### Обзор

Единый эндпоинт `POST /calculate` принимает операцию и операнды,
возвращает результат. Дополнительно есть `/` (информация о сервисе)
и `/health` (проверка состояния).

### Доступные операции

#### Бинарные (требуют `a` и `b`)

| Символ | Операция | Пример запроса | Результат |
|---|---|---|---|
| `+` | Сложение | `{"operation": "+", "a": 10, "b": 5}` | `15` |
| `-` | Вычитание | `{"operation": "-", "a": 10, "b": 5}` | `5` |
| `*` | Умножение | `{"operation": "*", "a": 10, "b": 5}` | `50` |
| `/` | Деление | `{"operation": "/", "a": 10, "b": 5}` | `2` |

#### Унарные (используют только `a`, поле `b` игнорируется)

| Символ | Операция | Пример запроса | Результат |
|---|---|---|---|
| `sin` | Синус | `{"operation": "sin", "a": 0, "b": 0}` | `0` |
| `cos` | Косинус | `{"operation": "cos", "a": 0, "b": 0}` | `1` |

> **Про `b` для унарных операций.** Поле `b` в текущем вконтакте
> API обязательно юзать для всех запросов, но для `sin` и `cos` его значение
> **не используется**, в следующей обнове поправлю.
>
> Примерчик: `sin(0)` с `b=0` и `sin(0)` с `b=999` дают одинаковый
> результат - `0`.
